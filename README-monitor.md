# Fleet Monitor — متابعة فنية لجهاز Termux

هذه نسخة مستقلة لا تعدّل `main.py` ولا `interactive_bot.py`.

## ما الذي تفعله؟

- لوحة حالة: البطارية، الاتصال، التخزين، ومدة التشغيل.
- تفاصيل البطارية والشبكة والتخزين والصوت بشكل منفصل.
- تنبيه عند بدء التشغيل، وسجلّ أخطاء دائري في `monitor.log`.
- تنفيذ منظم: مهمتان تعملان في وقت واحد وأربع مهام بحد أقصى في الانتظار.

## الإعداد لكل جهاز

استخدم ملف `config.py` الموجود، وأضف اسمًا واضحًا للجهاز:

```python
DEVICE_NAME = "Phone 01"
```

يجب أن يحتوي `config.py` كذلك على `TOKEN` و`MY_CHAT_ID` كما هو موجود في النسخة الحالية.
استخدم رمز بوت مستقلًا لكل جهاز إذا كان كل جهاز يشغّل الاستقبال المباشر من Telegram؛ لا تشغّل الاستقبال المباشر بنفس رمز البوت على أكثر من جهاز، لأن التحديثات ستتوزع بينهم بدلًا من أن تصل للجميع.

## التشغيل

على الهاتف ثبّت `requests` مرة واحدة وحزمة `termux-api`، ثم افحص الجاهزية:

```bash
python monitor_doctor.py
```

بعد نجاح الفحص شغّل التطبيق بالأمر الواحد:

```bash
python run_monitor.py
```

في Telegram أرسل `/start`، ثم استخدم الأزرار أو أحد الأوامر: `/status`، `/battery`، `/network`، `/storage`، `/sound`، `/uptime`.
